# Omni Biz Manager

Preciso criar um software de gestão de multiplas empresas, algo parecido com o Bling por exemplo. Sou sócio de 3 empresas. Uma delas é um escritório de advocacia, a outra é uma empresa de registro de marcas e a outra é de varejo no mercado livre. Minhas contas bancárias estão uma bagunça por conta disso, vez que não sei quanto recebo em cada, nem uma média mensal, também não tenho personalização, analise gráfica de mes a mes, semana a semana, detalhes importantes. Também, tenho diferentes tarefas pra fazer em cada empresa, então acabo me perdendo e me esquecendo de coisas pendentes para se fazer, queria que fosse possivel colocar as tarefas pendentes de cada empresa, criando um workspace para cada empresa
